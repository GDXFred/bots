Privacy policy

This policy covers the private tools described on the home page.

Who uses these tools

Each tool is used only by its owner, with the owner's own accounts. The tools are not offered to the public.

What data is accessed

With the account holder's explicit permission, a tool may read, organise and draft content in the account holder's own Google services, such as Gmail. Each tool requests only the access it needs.

How data is used

  • Data is used only to carry out tasks the account holder asks for.
  • Data is not sold, shared with third parties, or used for advertising.
  • Data may be processed by the AI service the account holder chooses to use, only to carry out those tasks.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage

Access tokens are stored only on the account holder's own devices. No data is stored on servers operated for these tools.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be raised as an issue in this site's repository on GitHub.
